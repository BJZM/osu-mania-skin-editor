# CSS Module Index

`index.html` loads the generated `style.css` bundle to keep the original
single-request runtime behavior. Edit the modules below, then run
`npm run build:css`. Do not edit `style.css` directly or reorder modules without
visual verification.

1. `tokens.css`: design variables, reset, scrollbars and base rules.
2. `player.css`: bottom player, progress, volume and speed controls.
3. `shell.css`: top bar, sidebar, main stage, info panels and notifications.
4. `skin-editor.css`: sidebar tools, modal, parameters and input controls.
5. `canvas-tools.css`: canvas selection, drag tools and parameter chips.
6. `texture-editor.css`: texture upload and animated texture sequence modal.
7. `help.css`: texture stretching help modal.
8. `cursor.css`: imported skin cursor overlay.
