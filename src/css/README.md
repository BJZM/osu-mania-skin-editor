# CSS Module Index

`index.html` loads the generated `style.css` bundle to keep the original
single-request runtime behavior. Edit the modules below, then run
`npm run build:css`. Do not edit `style.css` directly or reorder modules without
visual verification.

1. `tokens.css`: design variables, reset, scrollbars and base rules.
2. `components.css`: shared buttons, range sliders, checkerboards, thin scrollbars, modal overlays and toggle switches.
3. `player.css`: bottom player, progress, volume and speed controls.
4. `shell.css`: top bar, dropdowns, main stage, left info panel and canvas wrapper.
5. `shell-overlays.css`: startup panel, fullscreen button, loading overlay, toasts, export mode and unsaved exit modals.
6. `skin-editor.css`: skin editor tools group, dropdown menu, modal shell, header, toolbar, key pills and tabs.
7. `skin-editor-params.css`: parameter category blocks, per-track texture groups, parameter cards, hitsounds and tooltips.
8. `skin-editor-controls.css`: slider/number/text/select/color/texture controls, upload dropdown, raw ini view and editor footer.
9. `canvas-tools.css`: canvas selection card, drag tooltip, track drag mode, quick steppers, array chips and HUD font glyphs.
10. `texture-upload.css`: column colour / hold colour managers and texture upload spec modal.
11. `texture-existing-picker.css`: existing skin texture reference picker modal.
12. `animation-editor.css`: animated texture sequence manager and comboburst group modal.
13. `texture-image-shell.css`: texture image editor modal shell, confirmation sub-modals, header and tabs.
14. `texture-image-picker.css`: texture image picker view, texture library view and edit mode dropdown.
15. `texture-image-creator.css`: solid shape texture creator view and shape grid.
16. `texture-image-workspace.css`: texture image editor preview, zoom, RGB controls, long-body composer, footer and responsive rules.
17. `help.css`: texture stretching help modal and about modal.
18. `cursor.css`: imported skin cursor overlay.
