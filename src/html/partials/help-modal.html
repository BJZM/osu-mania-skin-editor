皮肤各贴图拉伸与尺寸规则指南
各轨音符与长条头 NoteImage0..K.png / NoteImage0H..KH.png
横向强制拉伸 底边贴合判定线
横向拉伸： 无视图片自身宽度，强制拉伸或压缩到该轨的 ColumnWidth。每轨各自拉满，所以同一张贴图在不同列宽下显示宽度也不同。
纵向高度： 高度不按当前列宽换算，而是取「基准列宽 × (图片高 ÷ 图片宽)」。基准列宽优先读 WidthForNoteHeightScale；该项为 0 或未写时，自动取所有列宽中的最小值（MinimumColumnWidth）。
对齐方式： 音符下落到判定线时底边精确贴合 HitPosition，不会越过判定线。
制作建议： 让图片宽高比等于「列宽 : 音符高度」即可完全不变形。各列列宽不一致时，较宽轨道上的音符会被横向拉宽、高度却仍按最窄列宽计算，最容易压扁；长条头 (NoteImageH) 使用与普通音符完全相同的规则。
长条长身 NoteImage0L..KL.png
横向强制拉伸 纵向按 768p 基准平铺
横向拉伸： 宽度强制拉伸填满当前轨道（ColumnWidth），与音符同一套横向规则。
平铺单元： 循环平铺的单段高度 = 图片原生高度 × 768p 缩放系数（@2x 贴图先折半），与列宽无关。所以改列宽只会改长身的宽度，纵向段落比例永远由贴图自身与画布高度决定。
平铺模式： 由 NoteBodyStyle 决定：1 从尾部平铺（默认，Percy LN 风格）、2 从头部平铺、0 整段拉伸（不平铺）。
不足一段： 长身比单段还短时不会压缩变形，而是按比例裁剪贴图：从尾平铺取贴图上段，从头平铺取下段。
覆盖范围： 从长条头部中心一路铺到尾部贴图顶端，尾部贴图覆盖在其上，避免半透明尾巴与长身之间出现断层或色差。
制作建议： 设计成可上下无缝循环的纯色条或垂直渐变条；单段尺寸按 768p 基准出图，长身无论多长多短都能平滑衔接。
长条结尾 NoteImage0T..KT.png
横向强制拉伸 上下翻转绘制
横向拉伸： 宽度强制拉伸匹配当前轨道宽度（ColumnWidth）。
纵向高度： 与普通音符同一套换算（基准列宽 × 图片宽高比），不是直接取原图像素高度；基准列宽同样是 WidthForNoteHeightScale 或最小列宽。
位置与方向： 以长条结束时间所在高度为垂直中心绘制，并被上下翻转（对应 osu! 长条尾的镜像绘制规则），所以图案不对称时上下方向会与预览图相反。
按键底图与按下状态 KeyImage0..K.png / KeyImage0D..KD.png
横向强制拉伸 底边贴齐键区最底部
横向拉伸： 贴图宽度强制拉伸匹配对应轨道宽度（ColumnWidth），与音符、长身同一套横向规则。
纵向高度： 高度 = 图片原生高度 × 768p 缩放系数（@2x 贴图先折半），与列宽无关：横向被拉宽或压窄都不会改变上下高度，所以贴图比例与列宽不匹配时按键会横向变形。
对齐方式： 底部贴齐画布（键区）最底边，不会对齐判定线。
状态切换： 按下瞬间整张无缝替换为 D 状态贴图，松开立即换回；两个状态建议保持尺寸一致以免跳动。
舞台左右边框 StageLeft.png / StageRight.png (或 mania-stage-left / right)
纵向强制拉满全屏 横向绝不拉伸
横向规则： 横向绝不拉伸，保持贴图自身像素宽度（1x 取原生宽度，@2x 贴图先折半参与换算），再随 768p 系数整体缩放。
纵向机制： 纵向强制拉满整个画面高度，从最顶端一直贯穿到底部。高度不匹配时会被强行垂直放大或缩小，带形状的图案会明显变形。
不拉伸高度： • 1x 普通贴图：高度设为 768px（对应 768p 官方基准高度，纵向 1:1 铺满，不发生比例形变）；
• @2x 高清推荐：高度设为 1536px（命名加 @2x，现代高分屏下点对点高清，完全不模糊不失真）；
• 1080p 点对点全屏贴图：高度设为 1080px (1x) / 2160px (@2x)。
制作建议： 含固定比例图标或徽标时，务必按 768px / 1536px 画布高度设计；若是纯边框线或发光条，采用纵向均匀纯色或垂直线性渐变即可天然无视拉伸。开启 SplitStages 时左右舞台各自绘制一对边框；如需隐藏边界，使用 1x1 全透明 PNG 或输入 blank。
舞台底栏 StageBottom.png / mania-stage-bottom
等比缩放不拉伸 水平居中 / 贴底
缩放规则： 宽高都按「原生尺寸 × 480p 缩放系数」计算（@2x 贴图先折半），横向与纵向等比缩放，不做任何拉伸，图片宽高比会被完整保留。
位置： 在舞台上水平居中，底边贴齐画布最底部。
轨道间距： 存在 ColumnSpacing 或开启 SplitStages 时，底栏会被逐轨裁剪，只在每条轨道范围内显示，轨道之间的空隙保持留空。
图层顺序： StageBottom 绘制在音符与按键之上，属于最上层覆盖贴图，会挡住落在舞台底部的音符；如需隐藏，使用 1x1 全透明 PNG 或输入 blank。
判定线指示光条 StageHint.png / mania-stage-hint
横向覆盖全舞台 中心对齐判定线
横向拉伸： 默认整条横跨所有轨道的总宽度（开启 SplitStages 时按左右舞台分段绘制）；若为单轨单独配置 StageHint0..K，则每轨各自拉满所在轨道宽度。
纵向规则： 高度 = 图片原生高度 × 480p 缩放系数（@2x 先折半），垂直中心精确对齐 HitPosition。注意纵向用的是 480p 系数，与 StageLight / LightingN 的 768p 基准不同。
与判定线区别： 那条贯穿的白线由 JudgementLine 单独控制；只把 StageHint 换成 1x1 透明图并不会隐藏白线，需要把 JudgementLine 设为 0 才会消失。隐藏贴图本身可用 1x1 全透明 PNG 或 blank。
按键按压光柱 StageLight.png / mania-stage-light
横向强制拉伸 底部对齐 LightPosition
横向拉伸： 宽度强制拉伸填满单轨宽度（ColumnWidth）。
纵向规则： 高度 = 图片原生高度 × 768p 缩放系数（@2x 先折半），底边对齐 LightPosition（按键动画垂直位置，默认 413）并向轨道上方延展。它跟的是 LightPosition 而不是 HitPosition，两者不同时光柱不会贴在判定线上。
触发与动画： 只要按下按键就亮起（与是否打到音符无关）；松开后在 250ms 内向下收缩回 LightPosition 并同步淡出。多帧序列的播放速度由 LightFramePerSecond 控制。
颜色： 由 ColourLight 着色，以加色方式叠加。注意 osu! 会把 alpha=0 强制改成不透明，写 255,0,0,0 得到的是不透明红光；想彻底关闭请把 StageLight 设为 blank。
击打爆光特效 LightingN.png / LightingL.png (lightingN / lightingL)
保持原图比例不拉伸 允许溢出相邻轨
尺寸规则： 完全不按单轨宽度拉伸，宽高同时按「原生尺寸 × 768p 缩放系数 × 缩放倍率」等比计算（@2x 先折半），图片宽高比完整保留。
缩放倍率： 由 LightingNWidth / LightingLWidth 换算，倍率 = 该数值 ÷ 30；填 0 或未配置时自动按「当前列宽 ÷ 30」，也就是特效宽度会跟着轨道宽度走。
位置： 水平中心固定在对应轨道中心，垂直中心固定在判定线 HitPosition，因此不能拖动位置，但可以在画布上点选并左右拖拽边缘改宽度。允许大幅溢出覆盖相邻轨道，是实现华丽爆光动画的核心贴图。
渲染方式： 以加色（lighter）方式叠加，越亮的像素越会把背景提亮。LightingN 是命中单键时的一次性爆发（寿命 200ms），LightingL 是长条按住期间循环播放的持续光效。
判定文字结果 mania-hit300g..hit0.png / hit300g..hit0.png
保持原图比例不拉伸 居中对齐全部轨道
尺寸规则： 完全不拉伸，按「原生尺寸 × 768p 缩放系数」等比绘制（@2x 先折半），不受单轨宽度限制。
位置规则： 水平方向绝对居中对齐所有轨道的中央；垂直中心由 ScorePosition（480p 虚拟像素）控制，可在画布上直接拖拽。
动画： 贴图判定总寿命约 220ms：先快速放大到 1.0 倍，再回缩到 0.70 倍保持，最后缩到 0.40 倍并淡出。Miss 只有轻微随机旋转、不会位移；多帧贴图按 20 FPS 序列播放。
缺图回退： 皮肤没有对应贴图时，会退化成矢量文字（300g 蓝 / 300 金 / 200 绿 / 100 蓝 / 50 灰 / Miss 红），尺寸与位置规则与贴图版一致。
分数与准度数字 score-0..9.png / score-comma / score-dot / score-percent
保持原图比例不拉伸 字距受 ScoreOverlap 控制
尺寸规则： 完全不拉伸，每个字符按「原生尺寸 × 768p 缩放系数 × 0.96」等比渲染（@2x 先折半）。分数显示在画面右上角，准度紧随其下，两者共用同一套 score-* 贴图。
固定宽度： 所有数字共用同一个槽位宽度，槽宽取自基准字符 score-5（缺失时用 score-0），数字在槽内居中。所以 0~9 宽度不一致也不会让分数左右跳动。小数点、逗号、百分号不参与等宽，按各自原生宽度排列。
字距重叠： 字符水平间距受 ScoreOverlap 控制：正数把相邻数字向左叠合、缩短间距，负数则拉大间隔。数值同样会随分辨率等比缩放。
百分号： 把 score-percent 换成 1x1 全透明图即可隐藏 % 并只显示纯数字准度；若提供超宽的透明 percent 贴图，则会被当作纯水平推移垫片用来调整准度的水平位置。
连击数数字 combo-0..9.png
保持原图比例不拉伸 位置受 ComboPosition 控制
尺寸规则： 横向绝不拉伸，每个数字按「原生尺寸 × 768p 缩放系数」等比渲染（@2x 先折半）。与分数不同，连击数字不强制等宽，各字符按自身宽度排列。
位置规则： 水平方向居中对齐全部轨道中央；垂直中心由 ComboPosition（480p 虚拟像素）控制，可在画布上直接拖拽。
字距重叠： 各数字横向间距受 ComboOverlap 控制，正数叠合、负数拉开，数值随分辨率等比缩放。
动画与颜色： 连击增长瞬间整组数字会纵向弹性拉伸到 1.4 倍再回弹（只是动画，不是贴图规则）；断连时旧连击数变红并向外扩散淡出。长条按住期间数字会改用 ColourHold 着色。
血条 scorebar-bg / scorebar-colour / scorebar-marker
保持原图比例 整体旋转 -90° 竖立
缩放规则： 背景与颜色条都按「原生尺寸 × 768p 缩放系数 × 0.70」等比缩放（@2x 先折半），不做非等比拉伸。
摆放方式： 整条血条逆时针旋转 90° 竖立、底部贴齐画布底部，位置在所有轨道的右侧（紧跟在轨道区之后）。
新旧样式： 存在 scorebar-marker 时按新版样式摆放，颜色条相对背景偏移 (7.5, 7.8)；没有 marker 则用旧版偏移 (3.0, 10.0)。两组偏移都会再乘 1.6 倍并随分辨率缩放。若没有实体背景图，偏移自动归零。
隐藏血条： 只要皮肤提供了 scorebar-colour 或 scorebar-bg，就视为作者已自定义血条、不会再回退默认皮肤。把 scorebar-colour 换成 1x1 全透明图即可彻底隐去血条本体（很多 mania 皮肤就是用这一招去掉血条）。
@2x 高清贴图制作标准规范 *@2x.png (例如 NoteImage0@2x.png, StageLeft@2x.png)
分辨率严格 200% 0.5x 尺寸高清渲染
尺寸倍率： 带 @2x 后缀的高清贴图，长与宽像素分辨率必须严格精确是普通 1x 贴图的整整 2 倍。例如 1x 尺寸为 30×60，则 @2x 必须为 60×120。
渲染机制： 读取到 @2x 贴图时，引擎会先把宽高各折半再参与全部尺寸计算，然后在 1080p / 2K / 4K 下按更高像素密度采样，从而得到锐利、无马赛克的边缘。上面每一条规则里说的「原生尺寸」，对 @2x 贴图都是先折半后的数值。
命名规范： 在原名基础上追加 @2x，如 NoteImage0@2x.png、mania-note1L@2x.png、StageLeft@2x.png；多帧序列写作 mania-stage-light-0@2x.png。查找优先级为 动态贴图 @2x > 动态贴图 1x > 静态 @2x > 静态 1x。
避坑指南： 只放 @2x 而没有配套 1x 时，在只认 1x 的场合（老工具、老版本客户端、部分预览器）会按原始像素当成 1x 渲染，导致贴图异常放大。本编辑器内部会正确折半，但对外发布皮肤时强烈建议 1x 与 @2x 成对提供。
