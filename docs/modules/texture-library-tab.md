# texture-library-tab

**一句话职责：** 管理贴图编辑器中的常驻“全部贴图”标签、搜索与复制命名/删除确认流程。

## 接口
- `initTextureLibraryUI()`：绑定常驻标签内容、搜索和操作确认弹窗。
- `renderTextureLibrary()`：重新读取所有已加载贴图并渲染标签内容。
- `textureLibraryUi.refresh()` / `getState()`：供编辑器刷新和历史恢复使用。

## 输入
- 当前皮肤图片仓库、搜索词和用户选择的操作；动画资源按真实帧路径逐项枚举。
- **前置条件**：`texture-library-operations` 与 `texture-library-view` 已加载。

## 输出
- 常驻标签内容、复制命名弹窗和删除确认弹窗。
- **后置条件**：操作成功后重新渲染贴图库、参数选择器与画布，并更新编辑器基线。

## 依赖模块
- `texture-library-view`：贴图库网格渲染。
- `texture-library-operations`：复制与删除业务操作。
- `texture-existing-sources`：资源枚举与过滤。

## 副作用 / 外部资源
- 绑定 DOM 事件、显示确认框、调用皮肤仓库变更和提示层。

## 非功能
- 标签不可关闭，打开编辑器时始终与“菜单”并列存在。
- 用户必须输入副本名称；空名称、非法字符和路径冲突会在确认前阻止提交。
- 异步复制期间禁用重复提交。

## 深度评估
- 将标签生命周期、搜索、弹窗和业务操作编排收敛到一个入口，贴图卡片只负责显示。
- 删除该模块后常驻标签会出现多处重复编排，因此保留。
